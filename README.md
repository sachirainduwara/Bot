## 📖 About
**SACHIYA MD** is a highly efficient and modern WhatsApp bot designed for stability and speed. Built with [Baileys](https://github.com/whiskeysockets/baileys), it offers seamless multi-device functionality and robust command handling.

## ✨ Core Features
* 📱 **Multi-Device Support:** Stay connected without your phone.
* 💾 **Secure Session Management:** Automatic session recovery via MEGA.
* 🚀 **Instant Notifications:** Get a detailed connection report in your inbox upon startup.
* 🛠️ **Customizable:** Easily extendable with custom plugins.
* ⚡ **High Performance:** Optimized code for minimal resource usage.

## ⚙️ Deployment
To deploy your own instance of SACHIYA MD, ensure you have the following environment variable set:

| Variable | Description |
| :--- | :--- |
| `SESSION_ID` | Your MEGA session string ID. |

## 🛠️ Built With
* [Node.js](https://nodejs.org/)
* [Baileys](https://github.com/whiskeysockets/baileys)
* [Express.js](https://expressjs.com/)
